# VIVA QUESTION BANK

**Q: What is the role of the Random Forest?**
A: To provide high clean-performance on tabular flow data using non-linear tree splits.

**Q: What is Option C?**
A: A dual-stream ensemble using 0.7*P_RF + 0.3*P_RobustMLP.

**Q: What does the adaptive attack do?**
A: It trains a differentiable neural surrogate to mimic the RF, then computes gradients on the surrogate to attack the full Option C ensemble.
